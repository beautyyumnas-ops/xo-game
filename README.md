# XO — Tic Tac Toe

A responsive two-player Tic-Tac-Toe web application built with HTML, CSS, and JavaScript.

The game includes score tracking, draw detection, animated winning states, and an interactive user interface.

## Features

- Two-player gameplay
- Automatic win and draw detection
- Score tracking across rounds
- Animated winning line
- Interactive result screen
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript
- GitHub Pages
